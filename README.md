# 🍀 งวดนี้แหละ (Ngord-Nee-Lae)

**งวดนี้แหละ** คือเว็บแอปพลิเคชันยุคใหม่สำหรับการตรวจสอบผลสลากกินแบ่งรัฐบาลและวิเคราะห์สถิติอย่างชาญฉลาด พัฒนาด้วยเทคโนโลยี Modern Web เพื่อมอบประสบการณ์ที่รวดเร็ว ลื่นไหล และแม่นยำที่สุด

## ✨ Key Features (ฟีเจอร์เด่น)

### 1. 🔍 Smart Lotto Checker (ตรวจผลรางวัลอัจฉริยะ)
*   **Multi-Check:** ตรวจรางวัลหลายใบได้พร้อมกันในช่องเดียว
*   **Easy Entry:** รองรับการเว้นวรรค (Spacebar) เพื่อแยกหมายเลข สะดวกกว่าการกรอกทีละช่อง
*   **Strict Validation:** ระบบล็อคเฉพาะตัวเลข 6 หลักเพื่อความแม่นยำสูงสุด
*   **Live Integration:** เชื่อมต่อ API ภายนอกเพื่อตรวจงวดล่าสุดได้ทันที แม้ข้อมูลในเครื่องยังไม่อัปเดต

### 2. 📊 Advanced Statistics (สถิติเจาะลึก)
*   **Historical Data:** รวบรวมข้อมูลย้อนหลังมากกว่า 3 ปี
*   **Top 10 Rankings:** จัดอันดับเลขที่ออกบ่อยที่สุดในแต่ละประเภทรางวัล
*   **Digit Heatmap:** ตารางวิเคราะห์ความถี่ของตัวเลข (0-9) ในแต่ละตำแหน่ง

### 3. 🔮 Spiritual & Beliefs (ศาสตร์แห่งตัวเลขและความเชื่อ)
*   **Dream to Number:** ระบบค้นหาความฝันและแปลงเป็นตัวเลขนำโชค พร้อมบทวิเคราะห์เชิงสถิติ
*   **Luck Randomizer (เซียมซี):** เสี่ยงทายเลขมงคลเฉพาะบุคคลด้วย UI ที่ทันสมัยและเรียบง่าย
*   **Wealth Calendar:** ปฏิทินรวบรวมเหตุการณ์สำคัญที่มักส่งผลต่อตัวเลขในแต่ละเดือน

## 🛠 Tech Stack (เทคโนโลยีที่ใช้)

*   **Framework:** [Next.js 15](https://nextjs.org/) (App Router & Turbopack)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Animation:** [Framer Motion](https://www.framer.com/motion/)
*   **Icons:** [Lucide React](https://lucide.dev/)
*   **Data Source:** Integrated with [Rayriffy Thai Lottery API](https://github.com/rayriffy/thai-lotto-api) (Scraped from Sanook.com)

## 🚀 Getting Started (วิธีเริ่มใช้งาน)

1.  **Clone the repository**
    ```bash
    git clone https://github.com/prame1/ngord-nee-lae.git
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```
    เปิดดูได้ที่ [http://localhost:3000](http://localhost:3000)
